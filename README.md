# RetroBox Android

Projeto Android nativo. O workflow do GitHub Actions compila o APK e publica um GitHub Release ao receber o primeiro commit na branch main/master.

**Estado:** protótipo CHIP-8 offline com controles de toque e gamepad. O núcleo SNES ainda não está integrado. Nenhuma ROM acompanha o app.

Após o build, o APK estará na aba **Releases** deste repositório como `v0.1.0`.
